# Security Incident Response

## Reporting
Report lost devices and suspected security incidents to the IT Security desk within 1 hour of discovery. Use the Report Phishing button for suspicious emails.

## Severity Levels
P1 incidents involve confirmed data loss or a service outage and require a response within 15 minutes. P2 incidents require a response within 4 hours. P3 incidents are handled within 2 working days.

## Containment
Disconnect the affected device from the network but do not power it off, so that investigators can preserve evidence.

## After an Incident
A post-incident review is held within 5 working days for every P1 incident.
